# Primeros pasos

## Quick path

<Steps>

1. **Instalar ywai**
   ```bash
   curl -fsSL https://github.com/Yoizen/dev-ai-workflow/releases/latest/download/install.sh | bash
   ```

2. **Configurar tu agente**
   ```bash
   ywai install
   ```

3. **Verificar**
   ```bash
   ywai doctor
   ```

4. **Abrir OpenCode 2 (`opencode2`) y usar**
   ```
   /learn-ywai
   ```
   o pedir trabajo directo:
   ```
   @dev Hola, ¿qué podés hacer?
   ```

</Steps>

<Aside type="tip">
ywai detecta el host (OpenCode 2 = `opencode2`, Claude Code, Cursor, etc.) y adapta automáticamente el formato de MCPs, permisos y plugins. El soporte de OpenCode v1 fue retirado.
</Aside>

## Tu primera tarea

| Qué pedir | Agente | Ejemplo |
|---|---|---|
| Pregunta simple | `@ask` | `@ask ¿Cómo funciona JWT?` |
| Código nuevo | `@dev` | `@dev Crea un endpoint GET /api/health` |
| Tests | `@qa` | `@qa Escribe tests para UserService` |
| Decisión de diseño | `@architect` | `@architect ¿Monolith o microservices?` |
| Feature completa | Orchestrator | `Implementa auth con JWT` |

## Comandos esenciales

| Comando | Qué hace |
|---|---|
| `ywai install` | Ecosistema, Engram, skills, perfiles, plugins/Graft |
| `ywai update` | Binario + re-aplica el entorno gestionado |
| `ywai doctor` | Diagnóstico de solo lectura (Engram, Graft, state) |
| `ywai skills` | Lista los skills disponibles |
| `ywai ui` | Abre el panel de control en el navegador |
