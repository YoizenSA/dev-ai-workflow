# Skills

## Qué son

Guías especializadas (`SKILL.md`). OpenCode 2 **anuncia** id + descripción; el body entra cuando el modelo llama la tool `skill`. `skills.txt` del agente es la allowlist.

## Cómo funcionan

```
Tú: "@dev Crea un componente React con Tailwind"
     ↓
OpenCode lista skills permitidos (id + descripción)
     ↓
El modelo llama skill("react-19") / skill("tailwind-4")
     ↓
Resultado: código que sigue esos patrones
```

## Ver skills disponibles

```bash
ywai skills
```

## Crear un skill personalizado

1. Crear `mi-proyecto/.opencode/skills/mi-skill/SKILL.md`
2. Agregar `mi-skill` al `skills.txt` del agente que deba usarlo
3. Reiniciar OpenCode (`opencode2`)
