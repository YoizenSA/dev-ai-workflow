# QA Finder

En los flujos de QA no hay un agente `qa-finder` separado: la exploración la hace **`@finder`**. Guía completa: [Finder](/dev-ai-workflow/agents/finder).

| Tarea | Ejemplo |
|---|---|
| Buscar tests | `@finder Find all tests related to auth` |
| Código sin cobertura | `@finder What code has no tests?` |
| Patrones | `@finder How do we write tests here?` |
| Qué necesita testing | `@finder ¿Qué archivos no tienen cobertura?` |

En el pipeline de QA Automation el orden es `@qa-analyst` → `@finder` → `@qa-dev` → `@qa-reviewer`.

<Aside type="tip">
`@finder` es read-only: ubica y resume código con rutas exactas para que `@qa-dev` no re-busque.
</Aside>
