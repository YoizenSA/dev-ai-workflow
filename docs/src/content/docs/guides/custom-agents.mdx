# Personalizar Agentes

## Qué podés personalizar

| Qué | Source (ywai) | Instalado (OpenCode 2) |
|---|---|---|
| **Comportamiento** | `AGENT.md` | Body del `.md` plano |
| **Permisos** | `permissions.json` | Array `permissions:` (action / resource / effect) |
| **Skills** | `skills.txt` | Allowlist: `skill * deny` + allow por id |

## Dónde vive un agente

**Source (lo que ywai instala):**

```
ywai/agents/core/dev/
├── AGENT.md
├── permissions.json
└── skills.txt
```

**Instalado (lo que OpenCode lee):**

```
~/.config/opencode/agents/dev.md
```

**Custom de un repo** (no lo toca el prune de ywai):

```
mi-proyecto/.opencode/agents/mi-agente.md
```

<Aside type="caution">
`ywai install` deja en `~/.config/opencode/agents/` solo el grupo activo. Un `.md` suelto ahí desaparece en el próximo install.
</Aside>

## Crear un agente de proyecto

<Steps>

1. **Crear** `.opencode/agents/docs.md` con frontmatter v2:

   ```markdown
   ---
   description: Writes and maintains project documentation
   mode: all
   permissions:
     - action: read
       resource: "*"
       effect: allow
     - action: edit
       resource: "*"
       effect: allow
     - action: skill
       resource: "*"
       effect: deny
     - action: skill
       resource: git-commit
       effect: allow
   ---

   You write and maintain project documentation.
   ```

2. **Reiniciar** OpenCode (`opencode2`).

</Steps>

## permissions.json (source ywai)

Mapa interno. ywai lo traduce a reglas v2 al instalar.

```json
{
  "read": "allow",
  "edit": "allow",
  "bash": "allow",
  "skill": "allow"
}
```

Si hay `skills.txt`, el install **no** deja `skill * allow`: niega el resto y permite solo esos IDs.

| Agente | read | edit | bash | skill |
|---|---|---|---|---|
| dev | allow | allow | allow | allowlist |
| ask | allow | deny | deny | allowlist |
| finder | allow | deny | deny | allowlist |

## skills.txt

Un id por línea. Eso es lo que el modelo puede cargar con la tool `skill`:

```
typescript
react-19
tailwind-4
git-commit
```

Lista vacía + `skill: allow` = todos los skills descubiertos (caro en tokens).
