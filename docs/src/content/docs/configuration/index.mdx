# Configuración

## Versiones de OpenCode

ywai requiere **OpenCode 2** (`opencode2`); el soporte de v1 fue retirado (ver [ADR-0001](../../adr/0001-drop-opencode-v1-support.md)). ywai escribe siempre formato v2: MCPs anidados en `mcp.servers.<id>` con `"disabled": true`, array `"plugins": [...]`, config de TUI/CLI en `cli.json`, permisos como lista ordenada de reglas `permissions:`, y delegación nativa de `subagent`.

### Autodetección

La autodetección prefiere `opencode2` si está en `$PATH`; si solo existe el binario `opencode` de v1, `ywai install` falla con un error claro.

## Estructura

OpenCode 2 usa el directorio global `~/.config/opencode/`:

```
~/.config/opencode/
├── opencode.json     # agents, MCP (mcp.servers), default_agent
├── cli.json          # tema, keybinds, plugins CLI
├── agents/           # Un .md plano por agente (lo instala ywai)
├── skills/           # Skills extra
└── commands/         # Slash commands
```

`ywai install` / `ywai update` **borra** de `agents/` cualquier `.md` que no pertenezca al grupo activo (core + qa-automation por defecto). Los custom van en el **proyecto**, no ahí.

## Perfiles de agentes (source)

En el repo / cache de ywai cada perfil tiene:

| Archivo | Qué contiene |
|---|---|
| `AGENT.md` | System prompt |
| `permissions.json` | Permisos (mapa interno; ywai lo exporta a reglas v2) |
| `skills.txt` | Allowlist de skills que ese agente puede cargar |

Instalado queda un solo archivo: `~/.config/opencode/agents/<nombre>.md` (frontmatter YAML + body).

## Personalizar

<Steps>

1. Editá el source (`ywai/agents/...` o el cache) o un agente de **proyecto**.
2. `AGENT.md` = comportamiento.
3. `permissions.json` = permisos. En el `.md` instalado se ven como `permissions:` (action / resource / effect).
4. `skills.txt` = IDs permitidos. OpenCode 2 anuncia solo esos; el body se carga con la tool `skill`.
5. `ywai update --agent opencode` y reiniciá OpenCode.

</Steps>

<Aside type="caution">
No dejes agentes custom solo en `~/.config/opencode/agents/`. El próximo install los prunea. Usá `.opencode/agents/<nombre>.md` en el repo.
</Aside>

## Configuración del proyecto

### AGENTS.md

```markdown
# AGENTS.md

## Convenciones
- TypeScript estricto
- Commits convencionales
- Tests con Vitest
```

OpenCode 2 descubre `AGENTS.md` hacia arriba desde el directorio de trabajo.

### Skills del proyecto

```
mi-proyecto/.opencode/skills/mi-skill/SKILL.md
```

o `.agents/skills/mi-skill/SKILL.md`. Reiniciá OpenCode. Para que un agente ywai pueda cargarlo, agregá el id a su `skills.txt`.

### MCP

En `opencode.json`, servers bajo `mcp.servers`. Para dejar uno apagado usá `"disabled": true` (`enabled` lo ignora v2).

## Verificar

ywai doctor
