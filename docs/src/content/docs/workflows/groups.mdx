# Agent Groups

## Qué son

Equipos predefinidos de agentes diseñados para trabajar juntos en tareas específicas.

## Los grupos

`ywai install` instala **core + qa-automation**. Los otros: `ywai groups enable <name>`. Disable quita esos `.md` (no core). El install también **prunea** leftovers (gentle, grupos apagados).

### Core

| Agente | Rol |
|---|---|
| `orchestrator` | Coordinador |
| `dev` | Implementa código |
| `designer` | Specs visuales y accesibilidad |
| `qa` | Escribe tests |
| `architect` | Decisiones de diseño |
| `reviewer` | Revisión de código |
| `devops` | Infraestructura |
| `ask` | Preguntas |
| `finder` | Búsqueda |
| `planning` | Planificación |
| `memory` | Memoria persistente |
| `advisor` | Segundo revisor (no se invoca directo) |

Subagent-only, fuera del install por defecto (llegan con `--all-groups`): `scenario-runner` (verificación BDD post-review), `planner-scout` + `planner-draft` (exploración y redacción de `@planning`).

**Para qué:** Desarrollo general.

### QA Automation

| Agente | Rol |
|---|---|
| `qa-orchestrator` | Coordina testing |
| `qa-analyst` | Estrategia |
| `qa-dev` | Escribe tests |
| `qa-reviewer` | Revisa tests |
| `qa-ask` | Preguntas de testing |

La exploración la hace `@finder`. **Para qué:** Testing completo con estrategia.

### QA Exploratory (sin grupo propio)

`exploratory-orchestrator`, `feature-summary`, `test-author`, `verification-orchestrator`, `qa-feedback`. Detalle: [QA Exploratory](/dev-ai-workflow/agents/qa-exploratory). **Para qué:** ciclo exploratorio post-implementación que termina en ADO. Se instalan con `ywai install --all-groups`.

### Experiment (opt-in)

`experiment/infra-docs`: mantiene la wiki de Infra como notas DIKS.

```bash
ywai groups enable experiment
```

## Delegación entre agentes

```
Core:
  orchestrator → [dev, designer, qa, architect, reviewer, devops, ask, finder, planning, memory]
  (advisor observa, no recibe delegaciones)

QA Automation:
  qa-orchestrator → [qa-analyst, qa-dev, qa-reviewer, qa-ask]
  (exploración: @finder)

QA Exploratory:
  exploratory-orchestrator → [feature-summary, test-author]
  verification-orchestrator → [scenarios, qa-feedback]
```

## Cuándo usar cada grupo

| Situación | Grupo |
|---|---|
| Feature nueva | Core |
| Bug fix | Core |
| Pantalla o UI | Core (`@designer` + `@dev`) |
| Testing completo | QA Automation |
| Testing exploratorio post-implementación | QA Exploratory (`/qa-exploratory`) |

<Aside type="tip">
Los únicos grupos instalables son `core` (siempre), `qa-automation` y `experiment`. Lo demás vive en disco y llega con `ywai install --all-groups`.
</Aside>
