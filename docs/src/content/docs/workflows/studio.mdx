# Workflow Studio

## Qué es

Un editor visual donde diseñás flujos de trabajo en un canvas y los exportás a opencode.

## Quick path

```bash
# 1. Abrir
ywai ui → http://localhost:5768/workflows

# 2. Diseñar
Arrastrar nodos → Conectar → Configurar

# 3. Exportar
Click "Export" → Se crea el command en opencode
```

## Tipos de nodos

| Nodo | Qué hace | Ejemplo |
|---|---|---|
| **SubAgent** | Delega a un agente | Dev, QA, Architect |
| **Prompt** | Instrucción fija | "Usa TypeScript estricto" |
| **AskUserQuestion** | Pregunta al usuario | "¿Mergeamos a main?" |
| **If/Else** | Decisión con dos ramas | "Si hay errores, ir a Dev" |
| **Switch** | Decisión con N ramas | Ruteo por tipo de cambio |
| **Skill** | Aplica un skill | angular, git-commit |
| **MCP** | Llama una herramienta MCP | Servidor + tool + parámetros |
| **Group** | Agrupa nodos colapsables | Fase "implement" con 3 agentes |

## Ejemplo

```
[Start] → [Architect] → [Dev] → [QA] → [If: Tests OK?]
                                          ├─ Sí → [Reviewer] → [End]
                                          └─ No → [Dev] → [QA]
```

## Qué se exporta

| Workflow element | opencode primitive |
|---|---|
| Workflow completo | Slash command (`/nombre`) |
| Orchestrator | Agent (`nombre-orchestrator.md`) |
| Nodos SubAgent | Agents (`nombre-agente.md`) |

Esos `.md` van a `~/.config/opencode/agents/`. Un `ywai install` posterior deja solo el grupo activo: un workflow exportado hay que volver a exportarlo, o guardarlo en `.opencode/agents/` del repo.

## Desinstalar o eliminar

- **Uninstall** (icono de goma, grupo Export): borra el slash command `/nombre` y sus agentes del destino elegido (target + env), sin tocar el diseño. El diseño queda en el Studio para re-exportarlo cuando quieras.
- **🗑️ Delete**: borra el diseño **y también** la implementación exportada (pide confirmación). Si exportaste a un env o a otro host, seleccioná ese destino antes de usar Uninstall; Delete desinstala del scope activo de la request.

### Huérfanos

Si borraste un workflow **antes** de que existiera Uninstall, su `/command` puede seguir vivo sin diseño detrás. El Studio lo detecta y muestra un banner: *"Implemented without a design: ..."*. El botón **Clean up** los desinstala de una vez. La detección solo marca commands con forma de workflow (`agent: <nombre>-orchestrator`), nunca los commands propios de ywai ni del host.

## Validación

El sistema verifica:
- ✅ Nodo de inicio y final
- ✅ Sin ciclos
- ✅ Campos requeridos completos

<Aside type="tip">
Studio es ideal para flujos recurrentes. Diseñá una vez, exportá, y todo el equipo lo usa como command.
</Aside>
