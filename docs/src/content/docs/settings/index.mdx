# Settings UI

## Qué es

Un panel de configuración visual donde gestionás ywai sin tocar archivos.

## Quick path

```bash
# 1. Iniciar el servidor y abrir
ywai serve -b
ywai ui

# 2. Ir a Settings
http://localhost:5768/settings
```

## Pestañas

| Pestaña | Qué configurás |
|---|---|
| **General** | Modelos, agente predeterminado, directorio de trabajo, AGENTS.md, SDD, notificaciones push |
| **Agents** | Perfiles instalados y su configuración |
| **Orchestrator** | Comportamiento del orchestrator |
| **Profiles** | Perfiles de modelo (balanced/fast/deep/inherit) |
| **Skills** | Ver disponibles, activar/desactivar |
| **MCP** | Servidores conectados, endpoints |
| **Providers** | Proveedores de modelos y auth |
| **References** | Referencias y material del sistema |

| Situación | Settings UI | CLI |
