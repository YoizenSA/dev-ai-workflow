# Seams

A seam is any of: a sub-task completed, a tool call about to be made, a file about to be written, a checkpoint verified, the topic changing, or anything addressed to the user.

Seams are where you audit. Between seams you work. Auditing mid-phrase makes the phrase worse.

| Refresh | How often |
|---|---|
| Ledger (goal, core, verified, open, next) | Every seam |
| The module you are actually using | Only when the phase changes, or the protocol starts feeling mechanical |
| Modules you are not using | Never |

`ywai ledger seam` prints the current ledger. If there is no ledger, that is not a failure — the pass is still solo/thin. Do not open one to make the command look busy.
